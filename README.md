# Computer Vision Journey

This repository documents my journey of learning Computer Vision
using Python, NumPy, and OpenCV.

I am building my knowledge step by step, starting from Python and
NumPy fundamentals and gradually moving toward image processing,
Computer Vision, Machine Learning, and eventually robotics.
